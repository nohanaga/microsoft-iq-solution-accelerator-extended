# 共通部品

2 アプリ間、または複数シナリオ間で実際に共有できるコードの抽出先です。現在、公開パッケージ・npm workspace・共通実装はありません。

## 抽出候補

| 候補 | 共通化するもの | 含めないもの |
| --- | --- | --- |
| domain | ID・単位・時刻・データ由来・根拠参照の型と入力検証 | コーヒー固有の配合式、税率、VIP 条件 |
| adapters | 複数箇所で必要になった接続・変換の共通処理 | あらゆる API を同じ認証で呼ぶ汎用プロキシ |
| evidence | 実行時点・出典・版・対象 ID を持つ判断記録 | 会話全文・アクセストークンの無制限保存 |

上記は候補名であり、空のパッケージを先に増やしません。初回はアプリごとの依存を維持し、利用箇所が確認できた処理だけを抽出します。親リポジトリへの `file:` 参照を、新しい不透明な巨大共通パッケージへ置き換えない方針です。

業務スキーマ、TypeScript の型、PostgreSQL DDL、Rayfin エンティティ、Fabric バインディングは役割が異なります。一方を編集しただけで他方も更新されると仮定せず、生成・検証が実装された範囲だけを自動化します。
