# 実行入口

データ基盤とアプリ初期準備の入口を実装済みです。全体の順序は [E2E 構築手順](../docs/end-to-end-setup.md)、データ CLI の詳細は [構築・配備・復旧手順](../docs/data-foundation.md) を参照してください。Rayfin 配備はアプリ内の CLI、受注同期は [独立サービス](../services/order-sync/README.md)、残る資源作成はポータル手順で接続します。全資源の一括配備・削除コマンドではありません。

| 実装 | 内容 |
| --- | --- |
| [import_sources.py](import_sources.py) | 元ワークスペースからの一回の選別移植。24 資産の移植済みで、通常の導入時は実行不要 |
| [import_public_prices.py](import_public_prices.py) | 世界銀行の公式価格取得。通常は同梱スナップショットを使い、更新時だけ実行 |
| [deploy.py](deploy.py) | `prepare` / `plan` / `apply` / `resume` / `status` / `record-operation` |
| [prepare_application.py](prepare_application.py) | ローカルだけで Rayfin 初期投入 SQL または Foundry Agent 作成要求を生成。対象設定・原本ハッシュ・未適用状態を記録 |
| [import_apps.py](import_apps.py) | アプリの一回限りの移植。`--setup-only` は元の予測・ML 入力・RTI 定義 15 資産の追加移植。導入時は実行不要 |
| [requirements.txt](requirements.txt) | Python の直接依存の固定版 |

原本移植と価格取得は実施済みです。新しい配備コードの実行は未確認です。移植後の生成コードは変更されているため、移植スクリプトの再実行を更新手順として使わないでください。既存ファイルと内容が異なる場合は上書きを拒否します。

## 工程と条件

| 段階 | 入力と出力 | 安全上の条件 |
| --- | --- | --- |
| 前提確認 | 選択機能、ツール、API、権限、容量 | 読み取りのみ。未対応機能を報告 |
| 準備 | シナリオ原本からカタログ・投入データ・意味定義を生成 | クラウドへ書き込まない |
| 配備計画 | 環境入力から作成・変更する資源を表示 | 費用と権限の確認前に配備しない |
| 配備 | Azure、Fabric、Foundry、アプリを依存順に処理 | 資源ごとの実行状態と所有情報を記録 |
| 初期投入 | 公開可能な合成原本とデータセットの版 | 実データや既存行を暗黙に置換しない |
| 同期 | EC outbox の反映 | 注文の正本を変更しない。再実行と整合確認 |
| 確認 | 読み戻し、権限、画面、機能別の受入結果 | モックと実サービスの結果を分ける |
| 停止・削除 | この環境で所有する資源一覧 | 対象を明示し、共有資源を削除しない |

移植済みの生成処理はこのディレクトリ内の Python パッケージを参照し、親 `.github/skills` を実行時に探索しません。データ基盤の配備は Fabric REST API と OneLake SDK を使用します。Azure 資源・アプリ・Foundry は全体手順のポータル操作・専用 CLI・生成要求で構築します。`azd` の入口は提供していません。

配備の途中停止では、記録済みの資源 ID と状態を読み、同じ資源を再利用できるようにします。既存の無関係な同名資源を自動採用しません。生成結果は環境別の Git 管理外領域に保存します。
